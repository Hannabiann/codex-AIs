# Выдача и возврат из архива — 0.30

В Codex-AIs подключены штатные формы выдачи, возврата и истории движения архива. Интерфейс и правила обработки выполняются из KS `arx` контрольного комплекта; отдельная форма на Rust не создавалась.

Основной адрес выдачи — `/20a?arx&mode=arxgiveout&force=1`. Старая ссылка `/20a?arx&mode=7&force` также открывает выдачу. В проверенной редакции KS 73090 число `7` уже обозначает отбор для уничтожения, поэтому совместимость старой ссылки добавлена только для точного GET без тела и дополнительных параметров. Отправленные формы и числовые номера их операций не переназначаются.

Пункт главного меню «Выдача документов из архива» проходит через `/83` и штатный `arxgiveout`. Исправлено преобразование `Request.PathObject` в текст: как у kodweb, скрипт формирует относительный адрес `?arx&mode=7&force=`, сохраняя текущий путь `/20a`. Раньше вместо этого появлялся несуществующий каталог `[function]`. Настройки объекта `PathObject` остаются доступны скриптам.

## Что работает

- Поиск и выбор объектов по штатной форме, в том числе несколько полей `nm_cases` в URL-encoded и multipart POST.
- Сохранение получателя, основания, причины, даты выдачи и планового возврата. Запись выполняется в DB4; штатный KS добавляет событие в историю движения.
- Формирование карточки-заместителя RTF из штатного шаблона с заполнением закладок.
- Поиск выданного объекта, подтверждение возврата, сохранение примечания и повторное открытие истории.

Запись разрешается при входе в проверенные обработчики выдачи, возврата и изменения даты хранения. Требуются авторизованный POST и штатный признак доступа архивариуса. Открытие страницы само по себе не разрешает запись, после запроса разрешение очищается. Остальные операции раздела этим изменением не разблокируются.

## Сравнение с kodweb

Проверка 27 ноября 2026 года выполнена на полной копии комплекта из 49 томов. В настройках этого комплекта архивируется объект «Дело». Один и тот же архивный объект 2025 года выдан и возвращён в каждом сервере из одинакового исходного состояния.

| Проверка | Результат |
|---|---|
| Переход из главного меню через `/83` и `arxgiveout` | Относительная ссылка совпала с kodweb; конечная форма выдачи открывается с HTTP 200 |
| Выдача, просмотр атрибутов, повторное открытие | HTTP 200; изменённые поля совпали с kodweb |
| Возврат с примечанием и история | HTTP 200; сохранённые поля и события совпали |
| Сравнение рабочего тома после выдачи и после возврата | В каждом случае изменилась одна запись; содержимое совпало после исключения времени выполнения из двух штатных полей. Других изменений записей рабочего тома у Codex-AIs не обнаружено |
| Карточка-заместитель | RTF совпал побайтно: 26 955 байт |
| Чтение результата Codex-AIs оригинальным сервером | Kodweb открыл атрибуты и историю, сформировал тот же RTF |
| Два выбранных объекта | Проверены повторные поля обеих форм передачи данных; выбранные номера и их порядок сохранены |
| Пустой результат поиска | Штатное сообщение, без ошибки выполнения |

После исправления перехода из меню в полном наборе `cargo test --locked --offline --bin codex-AIs` проходит 81 тест; 5 проверок с закрытыми фикстурами пропущены. Проверяются преобразование объекта каталога в ссылке с сохранением его свойств, разрешение записи, сброс состояния запроса, повторные поля формы и разбор RTF.

## Границы проверки

Полный цикл выдачи и возврата проверен для одного дела. Для нескольких объектов проверена передача выбора; массовая выдача, режимы отдельных документов и папок, изменение даты хранения и получение с удалённого архивного сервера требуют отдельных сценариев. Формы кликами в браузере в этой проверке не пройдены: инструмент управления Edge остановился на определении текущего URL. Серверные операции проверены через HTTP и сравнением DB4.

Адаптация обработчиков привязана к содержимому проверенной редакции `arx`. Для другого текста KS она не применяется автоматически. Заполнение RTF проверено на штатной карточке этого комплекта; пересекающиеся закладки, закладки между разными группами форматирования и двоичные данные внутри заменяемой области дают явную ошибку.

## Для разработчика

- [archive.rs](../src/ks/archive.rs) хранит разрешения текущего запроса и распознаёт старую ссылку.
- [source_archive.rs](../src/ks/source_archive.rs) подключает разрешение записи к трём проверенным обработчикам KS, сохраняя штатные формы и бизнес-логику.
- [http_form.rs](../src/http_form.rs) объединяет повторные числовые `nm_cases` через `;`, как ожидает штатный KS.
- [rtf_bookmarks.rs](../src/ks/rtf_bookmarks.rs) реализует `replaceBkmarkCharsInRTF`: разбирает границы закладок, экранирует текст и сохраняет оформление шаблона. Результат проверяется до записи в выходной поток.
