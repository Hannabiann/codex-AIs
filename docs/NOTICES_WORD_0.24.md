# Выгрузка аншлагов в Word в 0.24

Кнопка «Открыть в Word» у обычных аншлагов теперь возвращает файл `generator.doc`, как в kodweb. Внутри файла находится RTF: расширение `.doc` задаёт штатный генератор. Файл можно открыть в Word без надстройки `spdas.dotm`. Устанавливать Word или Excel на сервер для этой выгрузки не требуется.

## Причина ошибки и исправление

При нажатии кнопки форма отправляет `bword=1` в `/20a?convertToExcel`. Сервер возвращает страницу ожидания, которая повторяет запрос с `viewresult=1` и `freestr=1`. Затем штатный KS создаёт `new Document()`, заполняет его поле «Текст» таблицами и передаёт результат в `KodeksFormatRTFWriter`.

В kodweb это временный документ. Rust считал его обычным документом для записи в DB4 и завершал запрос ошибкой 501 при блокировке: `Persistent writes require an authenticated document editing request`.

Теперь такой документ существует в памяти запроса. Его блокировка не выделяет внутренний номер объекта; запись этого контейнера в DB4 запрещена. Отбор данных, проверка доступа и построение аншлага остаются в штатных KS.

Добавлены операции создания и копирования таблиц, строк, ячеек и форматированных фрагментов текста. RTF сохраняет размеры колонок, границы, отступы и параметры страницы из определения отчёта. Стили принадлежат конкретному запросу. Исправлен последовательный вывод частей текста, в том числе часов и минут, без перестановки фрагментов и лишних пустых абзацев в ячейках.

## Проверки

Проверка выполнена 23 ноября 2026 года на полном контрольном комплекте: 49 зарегистрированных томов, около 194 ГБ. Основная дата отбора — 1 октября 2026 года; форма 22 использует текущий день по своему алгоритму.

| Сценарий | Результат |
|---|---|
| 22 обычных шаблона с выводом в Word | Все сформировали RTF с заголовком скачивания `attachment; filename=generator.doc` |
| 13 завершившихся выгрузок kodweb | Совпали текст и порядок ячеек, границы колонок, текст вне таблиц и параметры страницы |
| Открытие в установленном Word | Файл Rust открылся; заголовки, таблица и время заседаний отображаются правильно |
| 24 расчёта HTML: обычные формы, отдельная форма 16 и настраиваемый вариант | Исходное содержимое ячеек, их объединение и ссылки совпали с предыдущей сборкой |
| Пустой период | Штатное сообщение об отсутствии результата, без ошибки сервера |
| Выбор всех судей | Сформирован RTF с полной выбранной таблицей |
| Две одновременные выгрузки | Результаты совпали с последовательными; главная, проверка связи Word и статус отвечали во время расчёта |

RTF сравнивался по содержимому и структуре: kodweb и Rust используют разные способы кодирования кириллицы, поэтому побайтное совпадение файлов не требуется.

Сравнение с оригиналом охватывает 13 шаблонов из 22. Word-выгрузка формы 15 в kodweb не завершилась за 360 секунд. Форму 13 в оригинале повторно не запускали: в [предыдущей проверке](NOTICES_0.23.md) её расчёт не завершился за 600 секунд. Все 22 выгрузки Rust завершились.

У настраиваемого аншлага и отдельной формы 16 штатной кнопки Word в проверенном комплекте нет. Исправление относится к существующим кнопкам генератора обычных аншлагов. Вложенные таблицы и изображения во временном RTF-документе пока не поддерживаются; проверенные шаблоны их не используют.
