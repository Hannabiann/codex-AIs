# Сокращения и термины

Пояснения к README, измерениям и технической документации codex-AIs. Обозначения отчётов сверены с меню проверенного комплекта АИС; названия и состав форм в других выпусках могут отличаться.

## АИС и отчёты

| Обозначение | Значение в документации |
|---|---|
| АИС | Автоматизированная информационная система. Здесь — АИС «Судопроизводство». |
| АС | Арбитражный суд; часть обозначения статистических форм. |
| 1АС, 1-АС, 1AC | Обозначение формы отчёта о работе арбитражного суда. В меню проверенного комплекта — «Отчет о работе суда ф.1АС». `1AC` — запись латинскими буквами, используемая в некоторых именах файлов. Это код формы, а не число одновременно выполняемых отчётов. |
| 01АС | Отдельная форма оперативной отчётности; в меню — «Оперативная отчетность ф.01АС». Начальный ноль отличает её от 1АС. |
| Z22.1 | Код формы «Нерегламентная статистика ф.Z22.1» в проверенном комплекте. В разговоре её могут сокращать до Z22. Буква Z и число обозначают форму; отдельной словесной расшифровки Z в исследованных материалах не установлено. |
| 22_1, StatOtchet221 | Внутренние обозначения ресурсов/обработчиков АИС, встречающиеся в коде и адресах. По одному имени обработчика нельзя определить выбранный отчёт: важны параметры формы. В измерениях указывается фактически выбранная форма — 1АС или Z22.1. |
| KS | Язык скриптов платформы КОДЕКС. Скрипты из томов описывают формы и прикладные операции. Здесь KS используется как имя языка, без предположительной расшифровки букв. |
| KS/DB | Исполнение скриптов KS и операций базы данных (DB — database). Исполнитель KS/DB — рабочий поток со своим состоянием интерпретатора и доступа к базе. |
| DB4, DBS, DB40 | Обозначения файлов/форматов томов КОДЕКС. Том — файл с объектами, полями, потоками и индексами. DB40 обозначает формат, поддержанный реализацией записи; это не число подключённых баз. |
| OID | Object Identifier — внутренний идентификатор объекта базы. Отличается от номера дела, входящего номера и идентификатора судебного акта. |
| nd | Параметр URL с внутренним номером документа/объекта в рассматриваемых маршрутах АИС. |
| KOD | Файл экспорта объекта КОДЕКС с расширением `.kod`; создаётся, в частности, при проверенном сценарии удаления. Не является общим журналом отката всего каскада. |
| CTF | Обозначение внутреннего текстового формата КОДЕКС. Точное развёрнутое название здесь не утверждается; его следует отличать от RTF, используемого Word. |

Период отчёта задаётся отдельно от его кода. «1АС за январь 2025» и «годовой 1АС за 2025» — разные объёмы расчёта. Год в названии шаблона может обозначать редакцию формы, а не период отбора. [Описание официальной формы 1 АС](https://www.consultant.ru/document/cons_doc_LAW_543711/bdfaaa328923423ed9537dfba301e48a92d1be93/).

## Профилирование и измерения

| Сокращение / термин | Расшифровка и пояснение |
|---|---|
| ETW | Event Tracing for Windows — механизм записи событий Windows: работа CPU, переключения потоков, обращения к файлам и другие события. Помогает определить, где выполняется работа и где возникают ожидания. |
| ETL | Event Trace Log — файл сохранённой трассы ETW. Может содержать пути и другие сведения о системе; сырые трассы в репозиторий не входят. |
| WPR | Windows Performance Recorder — инструмент записи трасс ETW. |
| WPA | Windows Performance Analyzer — программа для просмотра и анализа трасс производительности Windows. |
| WCT | Wait Chain Traversal — механизм исследования цепочек ожидания потоков. Короткий снимок WCT может не застать частую, но очень краткую блокировку. |
| CPU / ЦП | Central Processing Unit — центральный процессор. CPU time — сумма времени, реально затраченного процессором на потоки процесса; при параллельной работе может превышать длительность запроса. |
| Wall time | Время по часам от начала до конца операции, включая ожидания. В таблицах времени ответа обычно приведена именно эта величина. |
| I/O | Input/Output — ввод-вывод, например чтение и запись файлов. |
| FileIO / DiskIO | Имена групп событий файлового и дискового ввода-вывода. Логическое чтение файла может обслуживаться кэшем ОС; оно не обязательно означает чтение с физического накопителя. |
| PID / TID | Process Identifier / Thread Identifier — числовые идентификаторы процесса и потока. ОС может повторно использовать их после завершения процесса/потока. |
| PDB | Program Database — файл отладочных символов. Позволяет сопоставить адреса машинного кода с функциями и, при наличии сведений, строками исходника. Это не том судебной базы. |
| CPU-сэмпл | Периодический снимок места исполнения потока. Доля сэмплов приближённо характеризует распределение работы в выбранном окне трассы. |
| Стек вызовов | Последовательность функций, через которые выполнение пришло в текущую точку. Стек ожидания помогает понять причину блокировки. |
| CSwitch / ReadyThread | События переключения потоков и готовности потока к исполнению. Позволяют отделить работу на CPU от ожидания процессора и блокировки. |
| Mutex / критическая секция | Средства взаимного исключения: одновременно защищённый участок исполняет один поток. Наличие блокировки само по себе не означает, что она занимает основное время запроса. |
| Condvar | Condition variable — условная переменная. Позволяет потоку ждать события, например готовности общего кэша, не выполняя постоянный опрос. |
| RAM / private bytes | RAM — оперативная память. Private bytes — выделенная процессу частная память; этот счётчик не равен объёму страниц, находящихся сейчас в физической RAM. |
| КиБ / МиБ / ГиБ | Двоичные единицы: 1 КиБ = 1024 байта, 1 МиБ = 1024 КиБ, 1 ГиБ = 1024 МиБ. |
| HDD / SSD / NVMe | HDD — жёсткий диск; SSD — твердотельный накопитель; NVMe — протокол доступа к накопителям, обычно SSD через PCI Express. |
| x86 / x64 | В таблицах проекта — 32-битная и 64-битная сборки соответственно. Разрядность влияет на адресное пространство, но сама по себе не определяет скорость. |

## Отчёты Excel, сеть и запись

| Сокращение / термин | Расшифровка и пояснение |
|---|---|
| COM | Component Object Model — технология взаимодействия программных компонентов Windows. Штатный конвертер через неё управляет отдельным процессом Excel. |
| OLE | Object Linking and Embedding — связывание и внедрение объектов. В рассматриваемом KS имя `OLEobject` используется для доступа к автоматизации Excel. |
| MSXML | Microsoft XML Core Services — компоненты Microsoft для обработки XML; используются штатным конвертером. |
| XML / XPath | Extensible Markup Language — язык разметки структурированных данных. XPath — язык выбора узлов XML; по нему конвертер находит значения показателей. |
| XLS / BIFF8 | XLS — расширение старого двоичного формата книги Excel. BIFF8 — Binary Interchange File Format, версия 8: записи листов, значений, формул и оформления внутри книги. |
| CFB | Compound File Binary — контейнер со внутренними потоками; используется, в частности, в XLS. Поток Workbook содержит данные книги BIFF8. |
| RTF | Rich Text Format — формат текста с оформлением, используемый в обмене документами с Word. |
| Кэш формулы | Результат последнего вычисления формулы, сохранённый в XLS рядом с самой формулой. Сохранить формулу и пересчитать её — разные операции. |
| CalculateFull | Команда Excel для полного пересчёта формул открытых книг. В эксперименте вызвана явно один раз после заполнения отдельной книги. |
| HTTP / URL | Hypertext Transfer Protocol — протокол обмена браузера и сервера. Uniform Resource Locator — адрес ресурса, например страницы формы. |
| Keep-alive | Повторное использование HTTP-соединения для следующих запросов. Ожидающее соединение не обязано занимать исполнителя KS/DB. |
| API | Application Programming Interface — программный интерфейс: функции и правила, через которые одна часть программы обращается к другой. |
| SQL | Structured Query Language — язык запросов к данным. Здесь исполняется поддержанное подмножество запросов, используемых скриптами АИС. |
| SHA-256 | Secure Hash Algorithm, 256 бит — алгоритм контрольного хеша. Используется для проверки совпадения содержимого файлов и идентификации сборки. |
| Undo / redo | Отмена незавершённого изменения / повторное применение зафиксированного изменения при восстановлении по журналу. |
| fsync | Обозначение операции принудительной синхронизации записанных данных с хранилищем; конкретный системный вызов зависит от ОС. |
| Tokio | Имя библиотеки асинхронного исполнения Rust, а не аббревиатура. В проекте обслуживает сеть и диспетчеризацию; вычисления KS/DB идут в отдельных системных потоках. |
