# Открытие новых документов через d/hdoc: 0.27

Исправлена ошибка 404, при которой документ открывался из Word через `/99` и в редакторе атрибутов, но не открывался через `d`, `hdoc` и `doc`.

## Причина

В контрольных документах атрибут 1100 «Форма» ссылался на объект, отсутствующий в подключённых томах. Rust читал эту ссылку напрямую и прекращал построение формы. Штатная функция KS `MakeDoc` перехватывала исключение и возвращала HTTP 404, хотя сам документ существовал.

Kodweb пропускает отсутствующую сохранённую ссылку и использует стандартную форму области. Теперь Rust выбирает форму так же. Существующая форма документа сохраняет приоритет; при нескольких ссылках учитывается первая доступная. Если стандартной формы тоже нет, успешное открытие не имитируется.

Исправление действует при чтении. Пересохранять документы не требуется. Ошибки чтения и повреждения тома не принимаются за отсутствие формы. Явно запрошенная через `fnd` отсутствующая форма и отсутствующий документ по-прежнему дают отказ.

## Вкладка «Отправка»

Исправлено и второе расхождение: Rust показывал «Отправку» у документов без отправлений. Штатная функция `showLetters()` объединяет необязательные части результата через `+=`. Если все части отсутствуют, исходное значение и оба слагаемых равны `null`.

В KS сложение `null + null` оставляет пустое значение. Rust ошибочно преобразовывал оба операнда в числа и получал `0`. Из-за этого проверка `isEmpty()` считала вкладку непустой. Семантика подтверждена отдельной проверкой в штатном интерпретаторе KDB; результат исправления сопоставлен с kodweb через HTTP. Изменена операция сложения, а не список разрешённых вкладок. Числовой ноль остаётся содержимым: `null + 0` по-прежнему даёт `0`.

## Списки документов и участники дела

Исправлены два расхождения, найденные при сравнении карточки дела с kodweb.

Список документов раньше преобразовывался в готовый HTML при создании формы. Обработчик HTML уже не мог выбрать страницу и применить настройки списка. Теперь встроенные списки сохраняются до этапа вывода. Размер страницы читается через штатную функцию `GetListSize`, сортировка — из формы либо `GetListOrder`. Номер страницы не влияет на проверку пустых вкладок и преобразование полного поля. Для определения непустой вкладки достаточно наличия записей; строить аннотации всех документов не требуется.

В карточке дела расхождение адресов оказалось расхождением порядка участников. При сопоставлении по внутреннему номеру адреса всех восьми контрольных участников совпадали и до исправления. Rust выводил список в порядке записей, kodweb — с сортировкой по наименованию. Исправлен порядок вывода; правила чтения адресов и сами данные не менялись.

Для проверки на другом комплекте откройте новый документ из результата регистрации и из поиска, перейдите на вкладки текста и карточки, скачайте исходный файл. Повторите после перезапуска. Если в атрибутах указана недоступная форма, сравните выбор стандартной формы с kodweb.
