# Первый расчёт Z22.1 в 0.32

Проверка 28 ноября 2026 года. Нерегламентная статистика Z22.1 —
`/20a?statNoReglament`, выгрузка XLS. [Сокращения](GLOSSARY.md).

## Причина затрат

Запрос по признаку «С использованием ВКС» читает неиндексированное строковое
поле. При первом обращении строится общий кэш его значений на выбранных
документах. В контрольном комплекте это более миллиона записей из архивных
томов. Прежний путь разбирал все скалярные атрибуты каждой записи,
создавал объекты для них и затем оставлял только одно поле.

Обход шёл по внутренним номерам объектов. После правок и перемещения записей
такой порядок не совпадает с расположением данных в файле.

## Изменение

- Для построения строкового столбца читаются только нужные значения и OID.
  Остальные скалярные поля проходят проверку структуры без создания объектов
  и копирования строк. Текст документа и вложения не распаковываются.
- Записи выбранного тома читаются по номеру физического блока. Результат SQL
  по-прежнему сортируется по внутреннему номеру и не содержит дублей.
- Сохраняются проверки заголовка, контрольной суммы, OID и границы потоковых
  полей. Для нестандартной записи используется прежний полный декодер.
- Чтение привязано к одному снимку тома; перед публикацией кэша проверяется
  поколение данных. Изменившийся том перечитывается. Лимиты кэша и правила
  сопоставления строк сохранены; частичный столбец не становится полным.

Код не содержит списка томов, годов или специальных номеров полей для Z22.1.
Путь применяется к построению кэшей неиндексированных строковых атрибутов.
Формулы отчётов, KS, SQL-предикаты и запись DB4 не изменены.

## Условия и результаты

Полная копия комплекта, 49 томов. Windows Server 2025, Xeon Silver 4516Y+,
доступны 6 ядер / 12 логических ЦП и 32 ГиБ ОЗУ. Обычный `auto`: шесть
тяжёлых исполнителей, по одному месту Word, интерфейса и поиска.

Каждый замер первого месячного отчёта начинается в новом процессе, после
проверки главной и связи Word. Файловый кэш ОС не очищается. Время считается
до получения полного HTTP-ответа, без профилировщика. Серверная конвертация
Excel у kodweb входит в замер; открытие и пересчёт XLS на клиенте не входят.

Первый Z22.1 за январь 2025 года:

| Сборка | Первый запуск, с | Второй запуск в новом процессе, с | CPU, с | Пиковая ОЗУ процесса, МиБ |
|---|---:|---:|---:|---:|
| Codex-AIs до изменения | 31,62 | 31,10 | 32,52 / 31,59 | 486 / 487 |
| Codex-AIs после изменения | 19,69 | 20,14 | 19,94 / 20,45 | 484 / 484 |
| kodweb.exe | 251,92 | — | 172,59¹ | 623 |

Среднее время двух запусков Codex-AIs уменьшилось на **36,5%**, процессорное —
на **37,0%**. В каждой паре измерены первые расчёты в отдельных процессах,
а не повторное обращение к готовому кэшу приложения.

Число и объём логических чтений первого запуска совпали: 2 213 627 операций,
4 480 919 031 байт. Это обращения процесса, а не физический трафик диска.
Основной измеренный выигрыш — сокращение разбора атрибутов и выделений памяти.
Обход по физическому расположению меняет последовательность чтений;
отдельный замер на холодном файловом кэше или HDD не выполнялся.

¹ CPU kodweb указан для серверного процесса. Дополнительно работали kdb
(2,67 с CPU) и Excel (22,23 с CPU). CPU — суммарное процессорное время,
а длительность отчёта — время от отправки запроса до получения файла.

## Совпадение данных и проверки

- Четыре месячных XLS до и после изменения совпали со свежим результатом
  kodweb.exe: 8 листов, 42 447 значений и 476 формул в каждом, без расхождений.
- Годовой Z22.1 за 2025 год совпал с сохранённым результатом kodweb64 на том же
  комплекте: те же 8 листов, 42 447 значений и 476 формул. Это число ячеек
  шаблона, а не число дел. Старое время kodweb64 не использовалось в таблице.
- Контрольный 1АС: 13 листов, 37 947 значений и 17 250 формул совпали с kodweb.
  Почтовый отчёт за 01.01–28.11.2026: совпали 103 строки и 506 ячеек.
- Одиночное и два одновременных каскадных удаления прошли; получены все
  десять ожидаемых `.kod`, отсутствие объектов проверено через атрибуты и SQL.
  В этой серии удаления служат функциональной проверкой чтения ссылок.
- Пройдены 114 автоматических тестов, пять проверок с отдельными фикстурами
  пропущены. Новые тесты сравнивают выборочное чтение с полным декодером,
  проверяют пустые и повторные строки, границы потоков, усечённые данные,
  порядок OID и полноту покрытия кэша.

При сравнении XLS учитываются значения и смысл формул; дополнительные пустые
ячейки и эквивалентные формы записи BIFF не считаются расхождением. Кэш
результатов пересчёта формул Excel в проверку не входит.
