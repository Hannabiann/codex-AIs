# Word и блокировка статкарт в 0.24

Исправлены отправка формы статкарты с сообщением `repeated control parameter`, обычное подписание документа без ЭЦП, открытие выбранного документа из списка неподписанных, обработка запросов на разблокирование и сохранение определения после выбора заявления-основания. Сценарии Word раньше завершались ошибкой 501.

## Что изменено

**Сохранение определения.** При подтверждении атрибутов Word мог отправить некорректную необязательную дату в поле «Срок рассмотрения продлен до». Штатный `DocAttr` разбирает даты внутри `try/catch` и при ошибке оставляет поле пустым. Rust возвращал ошибку исполнителя, которую этот `catch` не перехватывал: весь `savedoc` завершался с HTTP 501. Ошибки аргументов поддерживаемых методов `Date.set*` теперь доступны обработчику KS. Диапазон дат не расширен; отсутствие реализации метода по-прежнему вызывает явную ошибку.

**Подписание.** Надстройка сначала сохраняет статус документа, затем вызывает `signdoc`. На этом этапе штатный KS преобразует RTF в текстовое поле DB4. В Rust отсутствовали необходимые операции импорта. Теперь поддержаны чтение RTF, обычное форматирование абзацев и простые таблицы, запись текста с метаданными в штатный формат. Исходное RTF-вложение сохраняется отдельно и не преобразуется.

**Открытие из списка.** В проверенном исходнике `getdoc` остался номер столбца от старой SQL-проекции. Ошибка проявлялась в ветке без отдельного объекта файла. Для этой конкретной версии исходника объект выбирается по имени столбца `OBJECT`. Порядок запрошенных Word атрибутов больше не влияет на этот выбор.

**Разблокирование.** Парсер принимает используемую формой KS запись функции с точкой с запятой перед телом. Исправлено копирование поля в том же документе: преобразование значения больше не происходит под несовместимой изменяющей блокировкой объекта Rust. Работают создание запроса, очередь `/99?UnlockDoc&` и его принятие. Решение о допустимости разблокирования по-прежнему принимает штатный KS.

**Статкарты.** Вложенные части формы повторяют `mode`, номер карточки и некоторые атрибуты. Обработчик принимает именно эти сочетания для `statcard171` и `statcard111`, сохраняя выбранный режим. Разные номера карточек и неоднозначные режимы отклоняются. Добавлен разбор русской даты, которую выводит сама форма.

## Проверка на полном комплекте

Проверка выполнена 23 ноября 2026 года на независимой копии: 49 подключённых томов, около 194 ГБ. Запросы воспроизводили протокол установленной надстройки `spdas.dotm`, включая набор атрибутов при открытии и реальный RTF из Word.

| Сохранение и перечитывание определения в Word 2024 | Через установленную надстройку сохранены атрибуты и текст, затем выполнено «Перечитать». Kodweb прочитал созданный через Rust документ; ответы атрибутов и выдачи RTF совпали побайтно |
| Обычное подписание подготовленного документа | Kodweb и Rust подтвердили подписание и вернули код связанного дела |

В первом прогоне у выбранной статкарты не были заполнены необходимые данные. Она не была заблокирована ни в kodweb, ни в Rust: проверялось совпадение штатного отказа после отправки формы. Успешная блокировка, повторное открытие и совпадение сохранённых атрибутов подтверждены в [отдельной проверке заполненной карточки](STATCARD_P_0.24.md).

Итоговая автоматическая проверка 0.24: 467 тестов прошли без ошибок, включая журналируемую запись, разбор форм, копирование полей и обработку некорректной даты из Word. Дополнительно проверены нормализация календаря и сохранение числового значения даты, используемого планировщиком как верхняя граница. Проверки, требующие отдельного окружения, не входят в это число.

## Границы поддержки

В рабочей версии 0.25 поддержка таблиц и кодировок RTF расширена, включая вложенные таблицы. Ниже описаны ограничения выпуска 0.24; актуальные результаты приведены в [проверке других шаблонов Word](WORD_TEMPLATES_0.25.md).

Проверено обычное подписание без ЭЦП. Криптографическая подпись и взаимодействие с токеном этим прогоном не проверялись.

Импорт внутреннего текста не является полной реализацией RTF. Поддержаны текст, выделение, выравнивание и простые таблицы. Вложенные таблицы, встроенные OLE-объекты и символы вне кодировки внутреннего текста отклоняются с ошибкой. Преобразование полей гиперссылок и оглавления в специальные структуры КОДЕКС пока не реализовано. Исходный RTF сохраняет их для Word.

Картинки остаются в исходном RTF; во внутреннее текстовое поле они не добавляются. В отдельном сравнении kodweb также пропустил изображение при таком импорте. Разбиение текста на абзацы и отдельные типографские символы могут отличаться; побайтное совпадение внутреннего текстового представления не заявляется.
