# Проверка codex-AIs 0.17

[Сокращения и термины: отчёты, ETW, KS/DB, Excel и другие обозначения](GLOSSARY.md).

Windows x64, 18 ноября 2026 года. Независимая копия полного комплекта из 753 753 файлов; исходный комплект не изменялся. Серверы переключались последовательно. Использован обычный kodweb.exe 5.3.2.120, без kodweb64.

- 337 обычных тестов прошли, 52 внешних теста пропущены в обычном запуске. Отдельно прошёл набор из 23 проверок writer с нативными томами и финальный набор из 10 проверок журнала.
- Семь аварийных завершений дочернего процесса; удаление с отметкой и без неё с прерыванием на семи этапах. Проверены точные байты восстановленного тома и резерва, индексы и старые читатели. Это программная имитация сбоя; питание накопителя физически не отключалось.
- 2 309 ключей, фиксированные, строковые и сегментированные деревья, два порядка удаления. Проверены одинаковая глубина листьев и оставшиеся ключи. Для штатных полей номеров дел порядок после удаления совпал с прежним за вычетом удаляемого OID.
- Проверены рост/сокращение резерва, читатель резервного файла, повреждённый журнал, посторонние изменения, жёсткие ссылки, конфликт редакций и параллельные писатели.
- Запуск без ручной настройки журналов: `/20a/`, карточка, вкладки, атрибуты, RTF, редакции `/99`, предпросмотр удаления и `/admin` вернули ожидаемые ответы.
- Оригинал прочитал атрибуты, две прежние редакции RTF и отсутствие удалённых Rust объектов. Затем создал и удалил собственные тестовые объекты на изменённой копии.
- Контроль исходного комплекта: шесть хешей неизменны. Из 24 контрольных файлов копии изменялись только рабочий том, аудит и счётчики поколений config.db4; байты записей конфигурации прежние.

Начальный расширенный запуск writer содержал три ошибки отсутствующих переменных для исторических фикстур; они не включены в успешный целевой набор. Новая проверка составного номера сначала обнаружила неподходящее строковое сравнение; исправлена удалением точного ключа с сохранением нативного порядка и успешно повторена.

Публичная копия содержит 64 производственных Rust-файла; 106 тестовых элементов удалены разбором AST. Данные, тестовые фикстуры и KS суда не публикуются. Windows EXE SHA-256: `4a7ca8d7274502f0b4fcd04de52c2356fb57e677bd123fc3e6b54e16534cde9f`.
