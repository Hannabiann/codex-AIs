Полный комплект проверки: 753 753 файла, 344 531 978 013 байт, независимая копия. Для проблемного дела выполнялось только построение предварительного списка (`fview=1`, каскад, без проверки ссылок чужих областей). Команда фактического удаления этого дела не отправлялась. Поэтому этот результат **не является испытанием записи большого каскада**.

Длительный читающий запрос остановлен после 30 минут наблюдения, затем сервер перезапущен и обычные страницы проверены повторно. Это граница данного испытания, а не возвращённый в программу таймаут KS. Ошибка лимита за этот интервал не повторилась, но успешное завершение полного каскада не установлено. Большой обход связей остаётся отдельной задачей производительности. Время взято из монитора запроса; `KODEKS_PROFILE=1`, файловый кэш ОС не очищался.

Прямые ссылки проверочного дела включают реестры передачи в архив. Штатный каскад может продолжить обход через общие реестры и выйти далеко за пределы одного дела; он не ограничен документами, показанными в карточке. Этот выпуск не меняет такую семантику. До фактического удаления требуется проверить полный список на расходуемой копии.

Обычный kodweb на той же копии не завершил этот предварительный список за примерно десятиминутное окно наблюдения от запуска процесса; чтение остановлено. Точное время самого запроса до прерывания отдельно не зафиксировано. Полного эталонного списка для этого большого случая нет, совпадение состава с оригиналом здесь не заявляется. Остальные исторические сравнения отдельно приведены в [BENCHMARKS.md](BENCHMARKS.md). Полная длительность kodweb неизвестна, коэффициент ускорения по этому запуску не вычисляется.

При переключении соблюдались остановка процесса → проверка процессов/порта → запуск другого сервера. Настройки v2rayN не изменялись. Оригинальный комплект не использовался для записи.
