# Проверка codex-AIs 0.17.1

Windows x64, 18 ноября 2026 года. Исправлен выбор рабочего тома при промежуточной записи объекта с областью 0 перед удалением. Журнал и порядок фиксации DB4 не изменены.

- 337 обычных тестов прошли, 52 внешних теста пропущены в обычном запуске. В обычный набор входят проверки журнала и восстановления. Отдельный набор аварийного завершения дочернего процесса из 0.17 в этом выпуске повторно не запускался.
- Выполнены 12 серий на реальных документах 2020 и 2026 годов: Rust, обычный kodweb и kodweb64; последовательные и два одновременных запроса. Каждая серия начинается с одинакового снимка данных.
- Проверены ожидаемый каскад, отсутствие всех удалённых объектов, доступность самого дела и набор выгруженных KOD. Созданы 99 KOD; 66 файлов Rust/x64 сравнены по полному декодированному содержимому с 33 файлами обычного kodweb.
- В 16 сравнениях `work.db4`/`workpost.db4` совпали наборы OID, отметки удаления и все поля 8,184 полных записей (суммарно по сравнениям). Это проверка результата по всему рабочему тому, а не только ответа HTTP.
- Копия возвращена к свежему снимку перед этой серией, сохранив пользовательские изменения, сделанные до проверки. Шесть контрольных SHA256 исходного комплекта неизменны.
- Финальный EXE запущен без `KODEKS_DATA_DIR` и `KODEKS_LOG_DIR`: прошли 12 HTTP-проверок главной, администрирования, Word, карточки, вкладок и атрибутов всех шести восстановленных документов. Подписи графиков проверены в светлой и тёмной теме.
- Очищенные производственные исходники сверены с исследовательской сборкой; тесты и данные суда не входят в публикацию. Из них собран и использован в измерениях Windows EXE.

Первый прогон Rust 0.17 обнаружил отметку письма в неправильном рабочем томе. Эти времена исключены из итоговой таблицы. После исправления оба прогона Rust за 2026 год повторены; совпадение рабочих томов подтверждено. Ранее созданные отметки автоматически не перемещаются.
