# Документация codex-AIs

Текущий выпуск и дерево исходников — **0.29**. Руководства сверены с исходниками 26 ноября 2026 года.

Разработчику форка начните с [DEVELOPMENT.md](DEVELOPMENT.md): там карта модулей, реализованные функции, ограничения и оставшиеся задачи. Пользователю — [запуск](BUILD_AND_RUN.md), тестировщику — [порядок проверок](TESTING.md). [README проекта](../README.md) содержит ссылки на бинарники.

[Журналы и ZIP-ротация 0.29](LOGGING_0.29.md): каталог, `error.log`, срок хранения и проверки.

## Как читать версии

- **Текущие руководства** описывают дерево 0.29. При изменении поведения обновляются вместе с кодом.
- **Проверки по версиям** фиксируют конкретный сценарий, комплект и ограничения того запуска. Отсутствие проверки не равно отсутствию реализации; удачный запуск на одном комплекте не подтверждает все версии KS и ОС.
- **Измерения и исследования** сохраняют исходные версии и числа. Они не являются повторными измерениями последнего EXE. PDF и PowerPoint с номером 0.18 относятся к исследованиям той серии.

Например, защита старой вкладки P описана в истории 0.22, но отменена в 0.25.1; в документе P сначала приведено действующее поведение. Обычное подписание Word уже работает, а серверная проверка ЭП с RSA не подтверждает весь клиентский цикл с ГОСТ и токеном. Четыре исполнителя на старой схеме — пример; сейчас по умолчанию действует auto.
