# Справочная система — 0.30

Страница: `/20a?infSystem`. Форма, поиск и карточка исполняются из штатных KS `infSystem` и `infSLibrary`. Сохранено оформление kodweb.

## Возможности

- Поиск по номеру дела, номерам производств, входящему номеру, дате регистрации и участникам. Дату можно задать точно, границей или интервалом.
- Несколько найденных документов выводятся списком; единственный результат открывается сразу. Сохранены тип документа, входящий номер, дата, судья, стороны и дата заседания в подписи результата.
- Карточка показывает состояние заявления, заседание, состав суда, связанные ходатайства и переходы к делу и истории.
- Администратор может менять названия и видимость полей отдельно для видов заявлений и жалоб. Параметры сохраняются в штатных записях DB4 и читаются kodweb после перезапуска.

## Исправления совместимости

Отбор служебных записей ограничен именами настроек справочной системы. Удаление элемента из KS `List` меняет только состав списка; удаление самой записи остаётся отдельной операцией. При очистке устаревших настроек список обходится с конца.

Пустой временный `Document` возвращает `null` при чтении отсутствующего атрибута. Это требуется для формы, в которой документ ещё не выбран. При сохранении настроек пропускается служебный элемент массива с номером категории.

В контрольном `config.db4` параметр `InfSystem` имел числовой тип и значение `0`. Kodweb находил документы, но завершал выдачу ошибкой при вызове строкового `split()`. Codex-AIs использует стандартный состав подписи для такого значения. Для сравнения полной выдачи kodweb проверен со строковым форматом `0;1;2;3;4;5;6;7;8`.

Переходы к истории используют `nMovement`. В проверенном скрипте объявления переменных перед первым `case` перенесены перед `switch`, с сохранением порядка инициализации.

Адаптация исходного текста применяется только при совпадении полного отпечатка проверенной редакции. Для `infSystem` проверена редакция **44579**. Другие редакции требуют отдельного сравнения.

## Проверки

На полном комплекте с 49 томами сопоставлены с kodweb.exe 5.3.2.120:

- семь вариантов поиска: по делу, входящему номеру, точной дате, интервалу, истцу, ответчику и без результатов;
- количество, порядок и подписи результатов, ссылки и значения полей;
- карточка найденного заявления, настройки двух категорий и пять видов истории: внутренняя, внешняя, распределение, назначения и результаты, текущие назначения и результаты;
- изменение подписи и флажка, чтение сохранённых настроек обоими серверами.

Проверено обновление устаревшей версии настроек: стандартные параметры создаются заново, повторное открытие работает, kodweb читает результат. Тексты, поля и ссылки в сопоставленных формах совпали; при сравнении исключена отметка времени формирования страницы.

В Chromium проверены поиск, переход из списка к карточке, очистка формы, календарь, сохранение подписи и флажка и возврат в начало. Режим IE не требуется.

Проверка сборки: 89 автоматических тестов прошли, 5 тестов с отдельными внешними условиями пропущены. Добавлены проверки удаления элементов списка, чтения отсутствующего атрибута временного документа и допустимого формата отметки версии настроек.
