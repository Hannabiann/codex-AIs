# Участие в разработке

Откройте issue с минимальным обезличенным воспроизведением либо сделайте fork. Присылая код, укажите, что имеете право предложить его под GPL-3.0-only. Использование ИИ допустимо; автор изменения отвечает за проверку результата, происхождение кода и отсутствие данных суда.

В PR опишите конкретную неисправность, поведение после исправления, проведённые проверки и известные границы. Для DB40/KS укажите, чем подтверждено совпадение с оригиналом. Для изменения записи нужны контроль исходного снимка, отказ при конфликте и повторное чтение результата.

Не добавляйте оригинальные EXE/DLL, штатные библиотеки KS, судебные документы и базы, пароли и журналы. Отладочные данные остаются локальными. Синтетические тесты, не содержащие чужих исходников и персональных данных, приветствуются: отсутствие старых тестов в первой публикации не является запретом добавлять новые.

Порядок расширения проекта и карта модулей: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Порядок ручной проверки: [docs/TESTING.md](docs/TESTING.md).
